  ¿Qué cambia cuando una persona puede intervenir en aquello que ocurre?

  - loop de interacción
  - posibilidad
  - acción

momentos:
  - titulo: Apertura
    cuerpo: >-
      En una experiencia audiovisual construimos una secuencia. En una
      interactiva, la persona puede actuar y alterar lo que ocurre después. La
      interacción como ciclo: posibilidad, acción, respuesta, interpretación,
      nueva posibilidad.
  - titulo: Laboratorio · Una sola acción
    cuerpo: >-
      Diseñar una experiencia con una única acción disponible. La riqueza no
      puede venir de añadir controles: debe surgir del loop.
  - titulo: Lente de proyecto
    cuerpo: >-
      ¿Cuál es el loop interactivo fundamental de nuestra experiencia?
puenteAudiovisual: >-
  El montaje ordena el tiempo por el espectador. El loop le entrega parte de
  ese orden a la persona: la secuencia deja de estar cerrada.
proposito: >-
  Introducir el ciclo de interacción como unidad de diseño. Desde esta sesión
  empieza a construirse el modelo de interacción de cada proyecto.
