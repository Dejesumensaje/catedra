  ¿Qué ocurre cuando el sistema también puede equivocarse?

  - incertidumbre
  - confianza
  - reparación
  - sistemas no deterministas

momentos:
  - titulo: Apertura
    cuerpo: >-
      Algunos sistemas no producen resultados completamente predecibles. Esto
      se vuelve especialmente visible en sistemas mediados por inteligencia
      artificial. Incertidumbre, control, confianza, comunicación y reparación.
  - titulo: Laboratorio · La máquina incierta
    cuerpo: >-
      Diseñar una interacción donde el sistema no pueda saber con certeza qué
      debe hacer. Decidir cómo comunica incertidumbre, solicita participación,
      propone alternativas, permite corrección, devuelve control y repara
      errores. La pregunta no es cómo esconder la incertidumbre, sino cómo
      participa la persona cuando el sistema no sabe.
  - titulo: Lente de proyecto
    cuerpo: >-
      ¿Dónde hay incertidumbre en nuestro proyecto y quién carga con sus
      consecuencias?
proposito: >-
  Tratar la incertidumbre del sistema como un problema de diseño de
  interacción, no como un defecto técnico a esconder.
